Amiga Core for Mega65
=====================

A port of the MiSTer minimig Amiga Core to the Mega65 machine / platform.

First ported to the Mega65 by Sy2002 in 2026.

Additional porting by Kiwi to expand its capabilities.

This repo continues with the work for a functionally complete version of the MiSTer minimig Amiga Core running on the Mega65.

The MiSTer and the Mega65 platforms, although FPGA based, used different architectures to achieve their aims.
The Mega65 Amiga Core has refactored the MiSTer implementation allowing for the architectural differences, 
while retaining the majority of the Core's code base from MiSTer.
